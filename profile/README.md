<h2>第一层：先确认页面背后是谁在运营</h2>
<p>这一层解决的问题是「我在跟谁签合同」。很多页面上找不到公司名，只留一个在线客服窗口和一个 QQ 邮箱，这种就要多留个心眼。真正运营方的页面，通常在页脚有完整主体信息、有可查的备案或注册编号、有固定的办公地址描述，而不是一整套模板文案。</p>
<h3>域名、主体与联系方式的交叉验证</h3>
<p>先看域名注册时间，whois 查一下，注册不满半年的站点要谨慎。再看页脚主体名称，拿去企业信息查询平台对一遍，看经营范围里有没有网络服务相关内容。最后看联系方式：有没有工单系统、有没有独立域名的邮箱、客服响应是不是只在工作时间。三项里有两项对不上，就把它当测评站看待，别当官方渠道。</p>
<h3>页面上的「官方」字样不构成证明</h3>
<p>标题里写「官方直营」「总代理」的页面非常多，但这几个字没有任何约束力。判断依据只能是主体信息、合同主体和发票开具方是否一致。如果要开票，先问清楚开票主体名称，再回头核对页脚，两个名字不一样就说明中间隔了一层。</p>

<h2>第二层：计费页面上的口径，一个字一个字读</h2>
<img src="/tp.png" alt="住宅IP计费页面核对流量与并发口径的操作界面">
<p>计费方式是这类页面最容易做文字游戏的地方。同样写「按流量计费」，有的只算下行，有的上下行都算；同样写「不限流量」，脚注里可能写着「公平使用，超出后限速到 1Mbps」。把鼠标移到小字上，或者把页面拉到最底部，通常能找到真正的规则。</p>
<h3>三种口径的写法差异与真实含义</h3>
<p>按流量计费看的是计量单位和计费方向；按并发计费看的是「并发」定义成端口数、连接数还是账号数；按端口计费看的是一个端口能不能多设备共用。这三件事在页面上经常混着写，最稳妥的办法是直接把你的使用场景描述给客服，让对方给一个具体的月估算，再反推口径。</p>

<h2>第三层：节点说明写得多细，决定它有多可信</h2>
<p>节点描述是最能看出服务商水平的部分。只写「美国节点」「欧洲节点」的，多半是从大池子里随机分配；写到城市、运营商、线路类型的，才有可能做到地区匹配。你可以拿同一个问题去问：这个节点属于哪个 ASN，是家宽还是 IDC 转售，出口地址段历史上有多少条滥用记录。答得上来的，说明确实在管节点；答不上来只会复述「纯净稳定」的，就当广告看。</p>
<h3>地区标注的三种粒度</h3>
<p>国家粒度最粗，只能满足「看起来在某个国家」；城市粒度能对上账号资料里的时区和语言习惯；运营商粒度最细，能影响部分平台对出口类型的判断。做长期账号，建议至少要求城市粒度，并且要求同一账号的出口城市在合同期内不变。</p>
<h3>线路类型描述里的关键词</h3>
<p>静态、独享、原生、双 ISP 这些词经常被混用。静态说的是地址在租期内不变；独享说的是这段地址只有你在用；原生说的是地址由当地运营商直接分配而非转售；双 ISP 说的是上游有两条运营商线路。四个词指向四件不同的事，别被一句「原生独享静态」直接带走，拆开逐条确认。</p>

<h2>常见问答</h2>
<h3>官网和分销页买，价格差很多，选哪个？</h3>
<p>答：差价的来源通常是售后层级。分销页便宜，但出问题时可能只能转达；官网贵一些，工单和技术对接更直接。账号数量少、能自己排查的可以选便宜渠道，长期账号建议走能直接对接技术的渠道。</p>
<h3>页面上写「支持试用」，但客服说需要先付款，正常吗？</h3>
<p>答：部分服务商的做法是先付小额测试费再退，或者用余额抵扣。关键是问清退款条件和到账时间，以及试用地址是否与正式套餐同批出口，否则试了也白试。</p>
<h3>怎么判断一个节点描述是不是编的？</h3>
<p>答：要一条测试地址，自己查 ASN 和归属运营商，再看页面写的运营商是否一致。描述里如果能给出具体 ASN 编号，可信度通常高于只写城市名。</p>
<h3>计费页面的小字条款有法律效力吗？</h3>
<p>答：通常构成合同的一部分，尤其是下单时勾选同意的版本。建议把当时的页面完整截图留存，包括小字部分，后续产生争议时这是最直接的依据。</p>
